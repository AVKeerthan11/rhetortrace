\# RhetorTrace



\*\*Contrastive Speech Analytics with Temporal Flaw Grounding\*\*



RhetorTrace evaluates spoken delivery by comparing a speaker against good reference deliveries of the same script.



It identifies:

\- What went wrong

\- Where it happened

\- How severe it was

\- What measurable evidence caused the flag

\- How the speaker can improve
